# Syed Abrar Haider Portfolio

This version uses the developed portfolio layout with Abrar Haider's professional content.

## Update profile picture
Replace `/public/profile/abrar-profile.jpg`.

## Add certificates
Place images in `/public/certificates/` and update certificate titles, issuer, dates, IDs, and descriptions in `index.html`.

## Run
Use a local static server or run the existing Vite project with `npm install` and `npm run dev`.
